# 博士机会地球与城市地图

在线入口：https://Lupen14461.github.io/phd/

2026-10-09数据快照：149条研究方向／项目记录，71座城市，20个国家／地区；不是149个开放资助席位。德国17条、12城。历史、待核、明确招募分别标示；最终条件以雇主最新信息为准。

## 浏览
拖动／缩放地球 → 点击国家 → 城市地图 → 城市对应导师与申请详情。另有阅读／表格、地区／方向／证据筛选、收藏笔记和最多三组比较。原5重点与Notion入口保留。
坐标为城市中心，不是实验室门牌。浏览器没有WebGL时可用平面地图。
收藏与笔记只保存在各设备浏览器，不会云同步或公开上传；保存不触发AI或日历。下载传输尚未自动验收，不作为唯一备份。

## 编辑
source/data.json是公开资料，source/template.html是自带地图资源的模板。运行：
~~~powershell
python source/build.py
~~~
生成index.html后检查，再Commit、Push，等待GitHub Pages部署。只改data.json不会自动重建HTML。
图存assets；许可存source/licenses，城市定位存source/city-locations.csv。
页面仅包含公开研究／招聘与资格政策，不包含私人主表、个人成绩、健康或通信。不要把个人材料加入此目录。

本轮真实Chrome检查地球／国家／城市层级、手机宽度、深浅配色和原有阅读功能。CSV内容生成已核，下载传输仍未确认。构建不等于已发布，部署状态以GitHub Pages和线上页面为准。
